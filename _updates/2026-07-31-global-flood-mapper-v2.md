This preprint introduces Global Flood Mapper v2, an open-access tool for flood mapping and exposure
assessment using Sentinel-1 SAR imagery, enabling flood depth estimation, geospatial data export, and
population exposure analysis directly in the browser.
Read the preprint [here](https://doi.org/10.31223/X54482).
