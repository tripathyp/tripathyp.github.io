I have built and maintained open-source geospatial tools since early in my career, and I
keep dedicating time to it.

## Tools

- **[pyrsgis](https://github.com/PratyushTripathy/pyrsgis)** — a Python package to read,
process and export GeoTIFFs. Available on PyPI and Anaconda, downloaded over 210,000 times.
- **[Global Flood Mapper](https://github.com/PratyushTripathy/global_flood_mapper)** — a
Google Earth Engine application that lets a user generate a flood map from Sentinel-1 SAR
data without processing large volumes of imagery or writing cloud code.
- **[COINS](https://github.com/PratyushTripathy/COINS)** — a tool to extract street
hierarchy from raw OpenStreetMap network data. Now integrated into the MomePy Python
package, and roughly ten times faster than the originally published version.
- **[LandSTAC](https://github.com/PratyushTripathy/LandSTAC)** — a Python project
connecting to the USGS LandsatLook STAC API. Currently in testing.

More on [my GitHub](https://github.com/PratyushTripathy).
